# 520008 迴圈 for 與 range()

請從標準輸入讀入一個正整數 `n`（1 ≤ n ≤ 100），然後：

1. 依序輸出 `1` 到 `n`，每個數字各佔一行
2. 最後一行輸出 `Sum = 總和`（1 + 2 + … + n）

重點：
- `for i in range(a, b):` 會讓 `i` 從 `a` 跑到 `b - 1`，注意不包含 `b`。
- 想從 `1` 數到 `n`，要寫成 `range(1, n + 1)`。
- 可以先設定 `total = 0`，在迴圈中用 `total += i` 累加。

閱讀例子（僅作參考，非本題答案）：
```python
for i in range(3):
    print("Hi", i)
# 輸出：
# Hi 0
# Hi 1
# Hi 2
```

例（僅示意）：
輸入：3
輸出：
```text
1
2
3
Sum = 6
```
