# 520007 條件判斷 if / elif / else

請從標準輸入讀入一個 0～100 的整數分數，依照下表輸出對應的等第（只輸出一個大寫英文字母）：

- 90～100：`A`
- 80～89：`B`
- 70～79：`C`
- 60～69：`D`
- 0～59：`F`

重點：
- `if` / `elif` / `else` 會由上往下檢查，第一個成立的區塊執行後就不再往下判斷。
- 比較運算子：`>=`、`>`、`<=`、`<`、`==`、`!=`。
- 每個條件後面要加冒號 `:`，區塊內的程式要縮排。

閱讀例子（僅作參考，非本題答案）：
```python
age = int(input())
if age >= 18:
    print("adult")
else:
    print("minor")
```

小提醒：請特別注意 `90`、`80`、`60` 這些「剛好在邊界」的分數。

例（僅示意）：
輸入：85
輸出：B
